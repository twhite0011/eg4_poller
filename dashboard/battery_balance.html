What this tracks

Cell-to-cell voltage spread across all three packs (cubix_1, cubix_2, lls_1), trended over weeks rather than the live snapshot the main dashboard shows. The question this answers: is the passive balancer actually closing the gap between cells, or is a flat spread a real capacity mismatch balancing can never fix? See each panel's own description (hover the info icon) for how to read it. Every number below comes from fields app/derive.py already computes on every poll -- nothing here needed a poller change to exist.
